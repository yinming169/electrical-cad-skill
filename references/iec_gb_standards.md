# 现行 IEC 与国家标准（GB/T）电气制图强制规范手册

本手册作为 `electrical-cad-skill` 的合规基准，已全面清理旧版过时标准号（如已废止的 `IEC 61346-2` 与 `GB/T 7251.1-2013`），统一对齐现行国际与国家标准。

## 1. 核心基础标准清单

| 领域 | 现行国家标准（GB/T） | 对应国际标准（IEC） | 本 Skill 强制落地要求 |
| :--- | :--- | :--- | :--- |
| **图形符号** | `GB/T 4728` 系列（1~13 部分） | `IEC 60617` 数据库 | 所有器件符号主轴 `x=0` 居中、遵循 EPLAN 4 mm 模数；PT 双圆相交、PE 外切圆三横杠、热元件矩形方波、熔断器开关带熔体框。 |
| **参照代号（位号）** | `GB/T 5094.2-2018` | `IEC 81346-2:2009` / `2019` | 采用单/双字母功能分类前缀（见下表），同一项目内禁止重号，带 `-` 前缀表示产品面、`=` 表示高层代号、`+` 表示位置代号。 |
| **电气文件编制** | `GB/T 6988.1-2024` | `IEC 61082-1:2014` | 图面布局清晰、文字不压线、跨页中断箭头标明 `页.列 / 网络名`、复杂二次图按主回路/电压/电流/控制功能分图。 |
| **低压成套开关设备** | `GB/T 7251.1-2023` | `IEC 61439-1:2020` | 工业默认污染等级 3、海拔 ≤ 2000 m；防触及 ≥ IPXXB、防固体外来物 ≥ IP2X；温升与短路耐受按成套设计验证。 |
| **固定封闭式成套设备** | `GB/T 24275-2019` | — | 金属隔板与 PE 有效等电位连接；MNS 典型尺寸 600/800×1000×2200 mm。 |

## 3. 核心电气工程校核规则

1. **互感器铁律**：
   - **CT 二次侧严禁开路**，且二次绕组必须**一点可靠接地**；准确度等级区分：`0.2/0.2S` 精密测量、`0.5` 计费、`1` 变配电所测量、`3` 一般保护指示、`5P20/B` 继电保护。
   - **PT 二次侧严禁短路**（二次额定电压 100 V），须配熔断器或微型断路器保护。
2. **TN-S 双电源与备自投**：
   - 市电/发电机或双变压器经 PC 级 ATSE 互投时，进线、母联与 ATSE 均须选用 **4P 开关**以切断 N 线杂散电流；PLC/综保测控回路配在线式 UPS（典型 2 kV·A）。
3. **异步电动机起动方式判据**：
   $$K_u = 0.75 + 0.25 \cdot \frac{S}{P}$$
   - $K_u \ge 6$：允许直接起动（DOL）；
   - $4 \le K_u < 6$：推荐降压起动（Y-△ 仅适用于正常运行 △ 接、6 出线端笼型电机；或自耦降压）；
   - $K_u < 4$：推荐软起动器或变频器（VFD）。
4. **谐波与通信**：
   - 谐波符号写作 $U_n / I_n$（禁用 `UH/IH`）；0.4 kV 公用电网 $\text{THD}_u \le 5.0\%$（奇次 4.0%，偶次 2.0%）。
   - 现场监控优先 RS485 + Modbus-RTU（超过 100 m 采用多模光纤），站级采用工业以太网 + Modbus-TCP。
