# 电气一次图 + EPLAN 二次图双轨制图细则

为避免一次配电系统图与二次控制原理图的图框、线型、表格和符号规则互相污染，本 Skill 严格实行**双轨分流制图**。


> **强制绘图与符号基准**：所有二次图及通用电气原理图的绘制方式与符号选型，均以用户提供的 **EPLAN 样图**（`examples/EPLAN工业标准自训练样图集_6页全套.pdf`）与 **EPLAN 符号库**（`symbols/mengge_symbol_catalog.json`、`symbols/standard-symbols-IEC-EPLAN-PRIM-MENGGE-134.dxf`）为最高基准，严禁偏离 EPLAN 4 mm 模数与既有符号几何。

## 1. 双轨核心差异对照

| 维度 | 轨道 A：电气一次图 (`primary`) | 轨道 B：电气二次图 (`secondary` / EPLAN) |
| :--- | :--- | :--- |
| **典型图纸** | 10 kV/6 kV 高压系统图、0.4 kV MNS 低压配电图、XL-21 动力柜、变频柜、壁挂配电箱 | 电机启停/星三角/软起/变频控制原理图、水泵阀门控制箱、PLC DI/DO/AI/AO 接线图 |
| **图框与分区** | 工程设计院 A2 一次图框（右下角标题栏+会签栏，无顶部 `0~9` 列号） | **EPLAN Electric P8 图框**（顶部 `0~9` 十列等分栅格 + 底部通栏标题栏 + `=高层/+位置/页码`） |
| **电路画法** | 单线系统图（带 `///` 三相标记、母线规格、虚线柜框与左上梯形铭牌） | 多线展开式原理图（顶部电位水平母线 + 垂直控制支路分列对齐） |
| **表格联动** | 顶栏 3 行柜体表 + 底栏 2 行或 6 行负荷表，列宽与上方支路中心线 `X` 坐标严格对齐 | 线圈正下方十字触点映像表（NO 列左 / NC 列右，标注 `/页.列`）+ 跨页中断箭头 |
| **图层分工** | 主母线/一次干线：`02_粗实线`；表格/辅助线：`01_细实线`；柜体边界/接地排：`DASHED`；文字：`07_文字` | 主回路：`02_粗实线`；控制/信号/端子：`01_细实线`；机械联动/现场虚线框/端子排穿透：`DASHED`；文字：`07_文字` |

## 2. 一次图两条不可违背的硬性修正

1. **塑壳断路器（MCCB）单线符号精确画法**：
   - 上端进线竖线必须精确终止于灭弧叉号 `×` 中心 `(x, y_top)`，**严禁竖线穿过 `×` 进入断口**。
   - 断口区间 `(y_top` 至 `y_bot = y_top - 820)` 必须完全空白断开。
   - 动触头斜刀闸从下端出线竖线顶点 `(x, y_bot)` 向左上斜伸至 `(x - 410, y_top)`；下端出线竖线紧接 `(x, y_bot)` 向下引出，严禁悬空。
2. **抽出式接插件（`︽`/`︾`）使用边界**：
   - **仅限 MNS 低压抽出式开关柜抽屉回路**（如小室高度 ≤ 400 mm 的马达抽屉、抽出式进线/母联/馈线）绘制上下接插件。
   - **固定式柜/箱**（GKD、GGD、XL-21、变频柜、壁挂配电箱）**严禁**绘制接插件符号。

## 3. EPLAN 二次图 10 大核心规则

1. 顶部 `0~9` 十列栅格 + 底部通栏标题栏（含设计/审核、项目名、图名、`=高层代号`、`+位置代号`、页码/总页数）。
2. 跨页源/目的中断箭头：左侧来线 `页.列 / -网络名 ▶`，右侧去线 `▶ -网络名 / 页.列`。
3. 完整引脚编号：`1/2, 3/4, 5/6`（主触点）、`13/14`（NO）、`21/22`（NC）、`A1/A2`（线圈）、`x1/x2`（指示灯）。
4. 线圈正下方绘制图形化触点映像表（Contact Mirror）。
5. DC24V 接触器线圈旁并联续流二极管；工频/变频或正反转回路强制双常闭电气互锁。
6. 变频器控制优先由 PLC DO 中间继电器独立启停，解耦主接触器辅助触点。
7. 变频器宏框：主回路含整流+直流母线+逆变拓扑；控制页含顶部虚线框与圆圈端子排。
8. PLC CPU / 扩展模块双层对称画法：上方 DO 驱动继电器排，下方 DI 接状态与按钮。
9. 模拟量 4–20 mA 传感器经端子排穿透虚线接入 AI/AO 模块，屏蔽层单端接入 PE 地排。
10. 字体与防卡死：DXF 统一配置 `gbcbig.shx` + `simplex.shx` + `ANSI_936`，确保 AutoCAD 2018+ 打开零弹窗、零乱码。
